# Product

<!-- impeccable:product-schema 1 -->

## Platform

adaptive

## Stack

Expo (React Native) with Expo Router, React Native Reanimated, and AsyncStorage.

## Users

Individuals managing personal tasks, daily to-dos, and errands who need a fast, intuitive, and distraction-free task tracker on mobile and web.

## Product Purpose

Provide a streamlined, zero-friction task management experience with immediate visual feedback, reliable offline persistence, seamless dark/light theme support, and dedicated routing for task inspection and updates.

## Positioning

A lightweight, distraction-free native CRUD task manager with fluid micro-interactions, responsive filters, and full keyboard and haptic affordances that feels like a handcrafted first-party mobile experience.

## Capabilities

- Instant task creation, completion toggling, and deletion with undo safety.
- Dedicated dynamic route `/edit/[id]` for focused task editing and status adjustment.
- Real-time search query filtering and tab-based status filtering (All, Pending, Completed) with item counts.
- Completion progress tracker with visual percentage indicator.
- Haptic feedback for tactile satisfaction on device interactions.
- Local offline persistence via AsyncStorage.
- Dark and light themes with automatic system default detection and user toggle.
